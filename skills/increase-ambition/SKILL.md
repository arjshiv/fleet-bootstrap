# Increase ambition

Use this prompt as the starting intent:

> give me crazy AI-pilled ways to take this project to the next phase. features only doable in the AI era. suggest 5 ideas, each one crazier than before

## Ground the ideas

Use the project context already available. If needed, inspect its brief, README,
or current experience to identify the user, the problem, and what already works.
If the project is unidentified, ask which project the user means.

Keep the project's purpose and the user's stated constraints. Treat today's
implementation as something that can change. Find an important activity that
AI could make possible, remove, or fundamentally reshape.

## Raise the ambition

Propose five distinct ideas, ordered from a substantial stretch to a moonshot.
Honor a different count or ambition level if the user requests one. Each idea
should increase the scale of the outcome, the autonomy of the system, or how
much the user can accomplish. Make the final idea the boldest departure from
the current experience while still serving the project's purpose.

For each idea, include:

- A concrete feature and a short, memorable name.
- A specific example of what the user could do or experience.
- The AI capability that makes this newly practical, such as reasoning across
  messy inputs, generating personalized experiences, or coordinating actions.
- The biggest unproven assumption and a small experiment that could test it.

Favor ideas that change the workflow or result. Make the five directions
meaningfully different. Explain what distinguishes an idea from a conventional
chat interface or a feature that ordinary rules could already deliver.

Be imaginative and specific. Mark speculative capabilities as assumptions.
Keep feasibility notes short and focused on the decisive uncertainty.

End by recommending which idea to test first and which has the largest upside.
For an ideation-only request, stop before implementation and let the user choose.
