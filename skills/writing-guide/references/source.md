# Source and adaptation

This skill was inspired by Mike Taylor's article, published November 16, 2026. It adapts the experiment design into a portable workflow and provides original prompts and a scoring utility. [How I Finally Got AI to Write Like Me](https://every.to/also-true-for-humans/how-i-finally-got-ai-to-write-like-me)

The article describes choosing format-matched writing, deriving substance briefs, reserving unseen examples, comparing anonymous drafts against an authored reference, reversing their order, and refining instructions from observed failures. It also argues for evaluating the guide with the model used for drafting and incorporating the author's later edits.

The article's reported results concern its author's corpus and experiments. This installation contains a procedure for calibration. It has not been optimized or evaluated on Arjun's held-out writing. The scorer's validation establishes arithmetic and input handling only.
